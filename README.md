Reflection:
In your own words, what is the difference between git add and git commit?

Through this activity, I learned the basic process of using Git for version control. I learned how to initialize a Git repository, check the status of my files, stage changes, create commits, and view the history of my project. At first, Git seemed a little confusing, but as I went through the process step by step, I started to understand how useful it can be when working on a project.

The difference between git add and git commit is simple. git add is used to select and prepare the changes that I want Git to include in the next version of my project. These changes are placed in the staging area first. Meanwhile, git commit is used to officially save those staged changes as a new version in the Git repository, along with a message describing what was changed.
